# Habit Tracker 🚀

Визуально впечатляющий трекер привычек — портфолио-проект по ТЗ.

## Стек

- **React 19 + Vite** — быстрый интерфейс
- **Tailwind CSS v4** — стили и темы
- **JavaScript** (без TypeScript)
- **LocalStorage** — все данные сохраняются в браузере
- Публикация на **GitHub Pages** готова (`base: './'` в `vite.config.js`)

## Функционал

- ✅ Добавление/удаление привычек (с выбором категории и эмодзи прямо из названия)
- ✅ Отметка выполнения за сегодня
- ✅ Категории: Здоровье 🍏, Учёба 📚, Спорт 💪, Развитие 🧠
- ✅ Contribution-график в стиле GitHub за последние 16 недель
- ✅ Статистика: серия 🔥, лучшая серия 🏆, % за неделю/месяц, прогресс за день
- ✅ Тёмная/светлая тема с переключателем
- ✅ Анимации: конфетти, hover-эффекты, плавные переходы
- ✅ Адаптивная вёрстка (мобильные + десктоп)

## Запуск

```bash
npm install
npm run dev      # режим разработки
npm run build    # продакшен-сборка в dist/
npm run preview  # предпросмотр сборки
npm run lint     # проверка кода (oxlint)
```
